# `starlight-save-file-component-docs`

Documentation for the `starlight-save-file-component` Starlight component, deployed at [starlight-save-file-component.netlify.app](https://starlight-save-file-component.netlify.app).

## Documentation

Run the documentation locally by running the following command in your terminal:

```shell
pnpm run dev
```

Content can be found in the [`src/content/docs/`](https://github.com/trueberryless-org/starlight-save-file-component/tree/main/docs/src/content/docs) directory.
